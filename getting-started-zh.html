快速上手

你的第一个 Claudito 项目

九个步骤，从一个简单项目到团队同步

耗时 专注投入约 30 分钟，包括检索、筛选、编辑和发布 LaTeX 文件 你需要 安装 Claudito（GitHub）、你的 ORCID、你同事的 ORCID 和邮箱、一个 GitLab 账户（GitHub 账户可选） 语言

Claudito 是什么——以及不是什么

一个本地命令行工具：一切都发生在你的研究文件夹里，在你的计算机上。

不是 AI 智能体：它绝不擅自行动，也绝不替你写论文。（完整承诺见：https://github.com/Pedrofariaeva/claudito-releases/blob/master/ETHICS.md）

本地模型（Ollama）离线处理筛选与分类。可选的自有密钥云端模型（Kimi、Claude）只回答筛选问题——仅标题和摘要，绝不涉及全文。

单向安全：你的工作只流向你自己的机器和你自己的 GitLab/Gitee。Claudito 不收集任何数据，也不向任何地方回传。

准备 1 —— 安装 Claudito

开始前请注册一个免费的 GitLab（推荐）账户和 GitHub（可选）账户：https://gitlab.com 和 https://github.com，并使用你将在 Claudito 中填写的同一邮箱。该邮箱将用于与团队共享你的项目。

在 Mac 上

打开 Terminal（终端）：按 Cmd + Space，输入 Terminal 并按回车。粘贴下面这行命令并按回车：

cd "$(mktemp -d)" && (curl -fsSL https://github.com/Pedrofariaeva/claudito-releases/releases/latest/download/claudito-macos.tar.gz -o claudito.tar.gz || curl -fsSL https://gitlab.com/Pedrofariaeva/claudito-releases/-/raw/main/claudito-macos.tar.gz -o claudito.tar.gz) && tar -xzf claudito.tar.gz && cd claudito-external-v* && ./install.sh

在 Windows 上

打开 PowerShell：按 Windows 键，输入 PowerShell 并按回车。粘贴下面这行命令并按回车：

[Net.ServicePointManager]::SecurityProtocol='Tls12'; Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force; try { irm https://github.com/Pedrofariaeva/claudito-releases/releases/latest/download/install.ps1 | iex } catch { irm https://gitlab.com/Pedrofariaeva/claudito-releases/-/raw/main/install.ps1 | iex }

同样的一行命令始终可在 GitHub 上找到：https://github.com/Pedrofariaeva/claudito-releases

只能在 Terminal 或 PowerShell 中运行。不要使用其他编辑器

如果提示无法连接，请再运行一次同一命令。它先尝试 GitHub，再尝试镜像；网络较慢时往往需要第二次尝试。

准备 2 —— 设置问题

安装完成后，Claudito 会按以下顺序询问这些信息：

你的姓名（希望别人如何称呼你）、你的 ORCID 和你的邮箱（最好是 ORCID 绑定的邮箱）。团队邀请依赖 ORCID 编号和邮箱，请仔细输入。

如果你是被邀请加入团队的，Claudito 会在这里找到邀请并让你加入该团队。确认码会发送到你的邮箱，请也检查垃圾邮件文件夹。

哪个文件夹是你的研究目录：接受 Claudito 建议的文件夹，或给出你已有的文件夹。

Ollama——Claudito 后端默认使用的 AI 引擎：自动安装、免费、无需密钥，我们推荐使用。该模型在你的机器上本地运行——筛选全程离线。（如果无法安装，设置会继续进行，之后可用 setup 再添加。）

Kimi 密钥（可选）：更强的筛选问答引擎。你的密钥留在你的计算机上，绝不共享——即使与你的团队也不共享。没有的话按回车跳过。

Claude 密钥（可选）：更强的筛选问答引擎。你的密钥留在你的计算机上，绝不共享——即使与你的团队也不共享。没有的话按回车跳过。

GitHub 用户名（可选）：拥有 GitHub 账户后，你可以用 Sign in with GitHub 注册 GitLab——在无法直接于 gitlab.com 注册的情况下这个办法可行。没有的话按回车跳过。

GitLab：输入你的 GitLab 用户名。Claudito 会打开已填好信息的 GitLab 页面。点击 Create personal access token，复制令牌，粘贴回命令行。

数据库密钥（可选）：没有密钥时检索已可通过免费数据库进行。密钥可以解锁更多数据库（IEEE Xplore、Scopus、Springer、Web of Science、CNKI……）。按回车跳过；之后可用 dbs setup 添加。

按回车保留已有内容。输入 back 返回上一个问题，或输入 quit 不保存并取消。最后 Claudito 会显示摘要供你核对，然后询问保存？

出了问题或跳过了某个问题？设置从不会半途而废。之后在项目列表处输入 setup 即可补答。

Claudito 中的任何 AI 都不会替你写论文或学位论文；它受一份伦理宣言约束，其边界仅限于提供各种辅助与自动化。更多内容见 https://github.com/Pedrofariaeva/claudito-releases/blob/master/ETHICS.md

准备 3 —— 确认它能运行

关闭窗口，打开一个新的 Terminal 或 PowerShell，

输入 clt 并按 Enter

查看版本号，例如 ✓ claudito v2.11.48。如果以后报告问题，这一行是首先要发给 Pedro 的内容。

如果无法识别 clt，关闭窗口并重新打开一个。

如果设置时跳过了任何问题，在开始处输入 setup。

如何开始

项目列表

Which one? [number/n/o/q/help]:

在这里创建项目（n）、管理团队（t）

输入项目编号即可打开该项目。

项目内部

[personal | myproject | Ollama] >

提示符显示你的项目名称。这里的其他一切命令（invite、abstract、harvest、plan）只在这个项目中生效。

如果 Claudito 回答“Invalid choice”（无效选择），说明你正处在项目列表。输入项目编号后再试。

创建项目

在项目列表
输入 n用于第一个项目（new project）（如果你已有项目，输入其编号，例如TYPE: 01）

给项目起一个不含空格的代号，例如 myproject。它会带着编号出现在你的列表中。

如果你还没有团队，项目暂时是私有的。这是正常的。如果你已有团队，Claudito 会询问属于哪个团队。

创建团队，并把项目放进去

先在项目列表，再进入项目
输入 t，查看列表并选择3（创建团队）输入团队名称，然后b返回

现在输入项目编号打开项目，把它放入团队：

输入 [[your-team-name]]

不要跳过第二部分。创建团队并不会把你已建好的项目移进去。少了这一步，你的同事加入的是一个空团队，看起来就像共享功能坏了一样。

你也可以直接在命令行输入：project team [[your-team-name]]

邀请成员

在团队菜单内
输入 4

或在团队菜单外，

输入 b先返回，然后……
选择一个项目编号，在项目内部：
输入 invite

Claudito 会询问对方的 ORCID，显示查到的姓名供你确认是本人，然后询问其邮箱地址。

邀请一位尚未加入你任何团队的人。这才是值得测试的情形。

告诉对方：他们会收到一封带验证码的邮件，可能会进垃圾邮件。如果找不到，请搜索 trackonperformance。

撰写摘要

在项目内部
输入 abstract

一个文件会打开。写几行项目简介，然后保存并关闭文件。

为什么先写摘要：下一步的检索会读取它来确定要找什么。

检索文献

在项目内部
输入 harvest

Claudito 会显示一个可据以检索的文档编号列表，并询问使用哪一个。

输入 abstract.txt 旁边的编号，不要直接按回车。选项 1 是空的计划模板，检索会去找它的占位问题，而不是你的主题。

这需要一些时间。它会检索你能访问的每个数据库，去除重复，并报告找到多少篇论文、其中多少篇附带 PDF。

探索帮助

在项目内部
输入 help或cheatsheet

help 按用途分组列出所有命令。cheatsheet 只显示最常用的命令。

挑一两个看起来有用的试试。其余功能就是这样学会的。

检查参考文献，然后写项目计划

在项目内部
输入 ref list然后ref organise然后plan

ref list 显示检索到的论文。ref organise 把它们整理进 references 下的文件夹。这个文件夹结构就是你的文档将遵循的形状。

看看这些文件夹，然后输入 plan，按照这个结构写下你打算做什么。

可选：screen all 让 AI 判断哪些论文真正相关。检索量较大时会很慢。

编译 PDF——以及幻灯片

在项目内部
输入 p

Claudito 会用你选择的出版商模板，把项目编译成排版好的 PDF 和一个 Word 文件——同一份文本，两种格式，始终同步。

幻灯片也可以：new slide 用学校模板开始一份演示文稿，build slides 把演示文稿编译为 PDF——同样的材料，另一种格式，无需 PowerPoint。

关闭计划，确认已保存，并正确退出

在项目内部
输入 plan完成后clt

保存并关闭计划文件。再次输入 plan，确认你的文字还在。

要在不懂 LaTeX 的情况下添加图、表或公式，先关闭文件，再在 Claudito 提示符下输入 format。在文件内部输入是无效的。

用 clt 退出，绝不要直接关窗口。clt 会保存并上传你的工作。直接关窗口会把一切留在你自己的计算机上，你的同事什么都看不到。

确认你的同事收到了项目

在你同事的计算机上
对方输入 clt

你的项目应该会出现在对方的项目列表中，并带有其内容：摘要、参考文献和你的计划。

项目与团队

新项目加入哪个团队：

还没有团队

项目是私有的。只有你能看到它。

有一个或多个团队

Claudito 会询问“这个项目属于哪个团队？”输入团队编号，或选择“不加入团队——自己留着”独自工作。

想之后再把项目加入团队，打开它并输入 project team team-name。同一条命令也可把项目移到另一个团队。

想把项目移出团队，打开它并输入 project team none。此后它不再被共享；已下载过它的同事保留他们的副本。

查看你的团队，输入 t 再输入 1。项目列表会在每个项目名后显示其团队，如 @aonipepe。

如果哪里不工作

给 Pedro 发三样东西：第一个界面上的版本行、你输入的内容、以及屏幕照片。

有了这三样，问题就能被定位。单靠一段描述通常不行。

help 列出所有命令，cheatsheet 列出最常用的命令。如果某个项目膨胀到几千兆字节以上，clean 会显示它携带了哪些不再需要的东西。
